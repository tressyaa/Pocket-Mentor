# Pocket-Mentor
Pocket Mentor is a motivational and productivity mobile application that is precisely created to address the challenges faced by students in maintaining their focus and consistency throughout academic careers. The application serves as a digital companion, combining daily motivational encouragement with structured planning and progress tracking.
